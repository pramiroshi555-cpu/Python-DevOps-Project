\# Python Calculator Application Using DevOps



\## Project Overview

This project is a simple Python Calculator

that performs addition, subtraction,

multiplication and division.



\## Technologies Used

\- Python

\- Git

\- GitHub

\- GitHub Actions

\- unittest

\- Docker



\## Features

\- Addition

\- Subtraction

\- Multiplication

\- Division

\- Division by zero handling



\## Automated Testing

Five test cases are implemented using

Python unittest.



\## CI/CD

GitHub Actions automatically executes

the test cases whenever code is pushed.



\## Docker

The application is packaged using Docker

and executed inside a container.



\## Execution



python app.py



\## Run Tests



python -m unittest discover -s tests -v



\## Docker Build



docker build -t python-calculator .



\## Docker Run



docker run -it --rm python-calculator
